Methods of verifying resident’s methods:  
 

* Wifi tracking: the SafeZone app can tell which building the resident is in. If they’re not in the alarming building, we know they’re safe. Only security has access to this information.  
  * Tells us if resident is onsite, but not if they are safe  
  * Requires security to contact wardens  
  * Security is busy during fire alarms  
  * I assume safezone is checked through a computer, which can’t be done while security is running around  
* Buddy system: someone on the same floor / near the resident can be responsible for checking if the resident has safely evacuated  
  * If someone sees that student is unable to leave the building they can tell warden  
  * Requires student to be in a visible position like a corridor (usually true but not infallible)  
* Direct warden check: the resident tells the warden when they’ve evacuated safely  
  * Sometimes the warden is tending to other emergencies  
  * Warden must manually check on every PEEP student  
  * Every warden has to be aware of the system  
  * Ineffective if resident isn’t in Princes Gardens  
  * Ineffective if resident is having a meltdown in the building  
  * The duty switches between warden and hall supervisors  
* Emergency buttons: if the resident is having difficulty evacuating they might be able to press one of the emergency buttons on each floor  
  * Useful that it provides a specific location  
  * I assume it calls security  
  * Requires ability to reach the button (resident can be placed close by)  
* PEEP devices, a separate hardware that you keep on you that connects to the building’s alarm system (alerts you to alarm and allows you to send response to security)  
  * Requires resident to have them on all the time  
  * Automatically turns on during fire alarms  
  * I assume it responds to security  
* Warden calls student to verify location  
  * Can verify if student is offsite  
  * Requires student to be able to respond to calls  
* Safezone alarm \- If resident cannot get out, they can attempt to call security through the safezone app  
  * Requires the ability to get phone, open app and hit call
